# --- Optional / platform-specific ---

# nvtx (NVIDIA Tools Extension) provides the Nsight Systems annotations used by
# flexkv.common.nvtx_compat. It is NVIDIA-only and is deliberately NOT a hard
# requirement: on CUDA-like accelerators without an NVIDIA GPU (e.g. Baidu
# Kunlun P800) the wheel is generally not installable, and there is no profiler
# to consume the events. flexkv.common.nvtx_compat transparently falls back to
# zero-overhead no-op stubs when the package is missing, so FlexKV runs
# unchanged either way.
#
# Install it explicitly on NVIDIA hosts to get profiler timelines:
#     pip install 'nvtx>=0.2.8'
# ...or via the extra declared in setup.py:
#     pip install '.[nvtx]'
